# Architecture

```
Browser (React/TS) ---> REST API (FastAPI) ---> PostgreSQL
       |                     |
Generated TS types      SQLAlchemy/Alembic
       ^                     ^
       +------ OpenAPI <-----+ (contract conformance)
                  ^
              TypeSpec
```

## Repo layout
- `contracts/` TypeSpec source of truth, OpenAPI output generated by compiler.
- `frontend/` Vite React TypeScript; type definitions generated from OpenAPI.
- `backend/` FastAPI app, ORM/migrations (to be implemented).
- `tests/e2e/` end-to-end acceptance tests (to be implemented).
- `docs/` product/architecture/ADRs, tasks and agent prompts.
- `docker-compose.yml` dev infrastructure.

## Database model (planned)
- `activities` (id, slug unique, title, duration_minutes, timezone, is_active)
- `weekly_windows` (activity_id, iso_weekday, start_local_time, end_local_time)
- `blocked_dates` (activity_id, local_date)
- `bookings` (id, activity_id, starts_at timestamptz, ends_at timestamptz,
  attendee_name, attendee_email, status, created_at)
- `admins` (id, email unique, password_hash)

## Booking consistency (blocking)
Client selects a slot returned by `GET /api/activities/{slug}/slots?date=YYYY-MM-DD`.
Server revalidates availability inside the booking transaction (never trust client-supplied availability).
Database must enforce exclusion of overlapping *confirmed* intervals per activity, see ADR-0002.
Translate conflict to HTTP 409. Check UTC normalization and DST ambiguous/nonexistent local times.

## API lifecycle
1. Lead proposes/approves `contracts/main.tsp` change.
2. Compile to OpenAPI (`cd contracts && npm run build`).
3. Regenerate TS types (`cd frontend && npm run generate:api`).
4. Backend implements matching routes and response/error codes; verify in integration tests.
5. QA verifies generated schema and real routes agree.

## Auth
Use a seeded admin, environment-provided credentials and short-lived bearer token for MVP.
No public admin registration. Protect `/api/admin/*` at runtime. Never store plaintext passwords.
Review CORS, token storage and CSRF/security before public deployment.
